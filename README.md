## Portfolio Focus

The portfolio presents my background in accounting, finance, data analytics, and data engineering, including my work on the Jezmu Finance project for small and medium-sized businesses.

## Featured Project: Jezmu Finance

Jezmu Finance is a Kenya-focused accounting and financial services project designed to support SMEs with structured financial data, bookkeeping workflows, reporting, and future automation opportunities.

The project combines accounting knowledge with data engineering practices, including:

- Relational data modelling using PostgreSQL
- Application development using Flask
- Containerized services using Docker
- Data validation and quality checks
- SQL-based transformation and reporting preparation
- A planned pathway toward repeatable ingestion and analytics pipelines
